## Empezar

```bash
git clone https://github.com/cristoferpina/umb-website.git
cd umb-website
```

Revisa las páginas de `umb/templates/` y sus referencias a `umb/static/`. La visualización completa puede requerir servir las plantillas desde un backend según las rutas utilizadas.
